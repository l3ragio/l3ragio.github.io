{%- comment -%} Translations (see the `translations` collection in _config.yml). Pages that exist in more than one language share a `translation_key`. The English original stays a normal post or Visual Story; every other language lives in the `translations` collection, which no listing reads (home, archives, categories, tags, feed, search, Visual Stories index), so each work is listed once. For a page with at least one translation this include emits: - for every version, plus x-default pointing at the version without `lang` (the site language); - a language toggle (EN | IT) that is inserted right below the page title on post and Visual Story pages. {%- endcomment -%} {%- if page.translation_key -%} {%- assign _tr_pool = site.posts | concat: site.visual_stories | concat: site.translations -%} {%- assign _tr = _tr_pool | where: 'translation_key', page.translation_key | sort: 'lang', 'first' -%} {%- if _tr.size > 1 -%} {%- for _d in _tr -%} {%- assign _l = _d.lang | default: site.lang %} {%- endfor -%} {%- assign _default = _tr | first %} {%- endif -%} {%- endif -%}
