A Typed Agent Action Framework with Prefix-Verdict Semantics

Technical report · 2026 / Agent / Triangle Dynamics

Davide Bragetti, Giuseppe Francesco Italiano

PDF (full text) DOI 10.5281/zenodo.22050705 Zenodo record Cite

Abstract

A compact typed framework for reasoning about agent actions against temporal properties evaluated on finite observation prefixes. Five footprint action classes at layer L_1 - READ, THINK, SPEAK, WRITE, ACT - are given a uniform typed signature with an explicit carrier partition (transient M vs persistent P). A three-action quotient q_{5->3} identifies SPEAK, WRITE, ACT into RESPOND and is proved conservative on carrier-insensitive families (rem:a3-conservative). The principal formal result is FA-REENTRY (prop:reentry): the architectural conditions under which a WRITE followed by a delayed READ can recover the payload, delimited by the carrier-lifetime clause Delta <= L_C.

A dedicated section (sec:temporal-typing) maps footprint predicates onto the Safety / Cosafety / Liveness / Coliveness intersection algebra of Bragetti-Italiano (Zenodo 10.5281/zenodo.21099448), separates the FA-REENTRY event formula (finite Cosafety, rung 3) from the architectural reentry claim, and documents an optional refinement-confirmation certification layer (Bragetti, Zenodo 10.5281/zenodo.22028019) for FG-persistence stabilisation and system-level response-mechanism convergence, with an explicit temporal-class / refinement-confirmability orthogonality witness (GF p and FG p share indicator (0,0,1,1) yet only FG is RC-confirmable).
